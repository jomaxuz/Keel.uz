        1. Base URL и окружение
        В интеграционном продукте базовый адрес обычно один из:


            http://localhost:8080
            http://localhost:12346


        Рекомендуется использовать переменную окружения:


            # PowerShell
            $env:BASE_URL = "http://localhost:8080"
            # или
            $env:BASE_URL = "http://localhost:12346"




        2. Базовые эндпоинты

            GE      /api/v1/contragents                     Информация о компании/контрагенте
            T




            GE      /api/v1/contragents?refresh=1           Принудительное обновление данных
            T




            PO                                              Выполнение кассовых операций (единая
                    /api/v1/operations
            ST                                              точка входа)




        Заголовки запроса:

            Content-Type: application/json; charset=utf-8
            Accept: application/json




        3. module_operation_type — тип операции
        Поле module_operation_type определяет тип кассовой операции:


            Код        Тип операции        Описание


              1        open shift          Открытие смены


              2        close shift         Закрытие смены


              3        sale                Продажа

        4. Единицы измерения и деньги

            ⚠ receipt_gnk_receivedcash, receipt_gnk_receivedcard, receipt_sum — передаются в
            ТИЙИНАХ (сум × 100).



            ℹ Все цены внутри items[] (product_price, total_product_price, product_discount, other) —
            передаются в СУМАХ.



        Маркировка и штрихкоды:

            ⚠ Поля product_mark, product_label и элементы product_barcodes нужно
            отправлять ПОЛНОСТЬЮ, не обрезая строку и не усекая символы/хвосты. Если
            данные приходят из сканера — передавайте их 1:1 (как есть), без нормализации
            длины.

        6. Поля items[] — формат toSellJson()

          Поле                        Тип          Описание

          product_id                  int          ID товара

          product_name                string       Название товара

          product_price               float        Цена за 1 единицу (в сумах)

          total_product_price         float        Итоговая сумма по позиции (в сумах)

          product_discount            float        Общая скидка по позиции (в сумах)

          count                       float        Количество (может быть дробным, напр. 1.550)

          product_vat_percent         int          Ставка НДС в процентах

          product_without_vat         bool         Признак освобождения от НДС

          ikpu                        string       Код ИКПУ (обязательно строкой)

          packageCode                 string       Код упаковки (обязательно строкой)

          product_package             string       Единица упаковки

          product_package_name        string       Название единицы (напр. "шт")

          product_barcode             string       Основной штрихкод

          product_barcodes            array        Массив штрихкодов [{type, barcode}]

          product_mark                string       Код маркировки (полный, без усечения)

          product_label               string       Метка маркировки (полный, без усечения)

          classifier_class_code    string    Код классификатора

          no_check_mark            bool      Не проверять маркировку

          is_bottling              bool      Признак розлива (без проверки марки)

          other                    float     Сумма, списанная баллами (loyalty)



        Нюансы:
        • count можно передавать дробным значением, например 1.550.
        • ikpu и packageCode — обязательно строкой, даже если выглядят как число.
        • is_bottling: true — признак розлива; такие позиции без проверки маркировки.
        • fixed_qty — "порция" для розливного алкоголя.
        • Для розлива критично заполнять packageCode корректным кодом упаковки (по мл).
        • product_price — цена за 1 единицу.
        • product_discount — общая сумма скидки по позиции (на всё количество).
        • other — сумма, списанная баллами (loyalty).
        • commitent_tin — ИНН коммитента.
        • client_id и client_name можно не передавать (необязательные поля).

        Получить информацию о компании:

            curl "$env:BASE_URL/api/v1/contragents"
            curl "$env:BASE_URL/api/v1/contragents?refresh=1"




        Продажа (type = 3):

            curl -X POST "$env:BASE_URL/api/v1/operations" `
            -H "Content-Type: application/json" `
            -d '{
            "module_operation_type": "3",
            "receipt_sum": 100000,
            "receipt_gnk_terminalid": "FM_TERMINAL_ID",
            "receipt_cashier_name": "CASHIER",
            "receipt_gnk_receivedcash": 100000,
            "receipt_gnk_receivedcard": 0,
            "receipt_gnk_time": "2026-04-06 12:34:56",
            "shift_id": "SHIFT_GUID",
            "items": [ { "product_id": 123, ... } ],
            "location": { "Latitude": 41.0, "Longitude": 69.0 }
            }'




        Возврат (type = 4):

            curl -X POST "$env:BASE_URL/api/v1/operations" `
            -H "Content-Type: application/json" `
            -d '{ "module_operation_type": "4",
            "receipt_sale_id": "RECEIPT_SALE_ID",
            "RefundInfo": { "ReceiptSaleId": "RECEIPT_SALE_ID" } }'




        Открытие/Закрытие смены и X‑отчет:

            # Открытие смены
            curl -X POST "$env:BASE_URL/api/v1/operations" `
            -d '{ "module_operation_type": "1", "shift_id": "...", ... }'

            # Закрытие смены
            curl -X POST "$env:BASE_URL/api/v1/operations" `
            -d '{ "module_operation_type": "2", "shift_id": "...", ... }'

            # X-отчет
            curl -X POST "$env:BASE_URL/api/v1/operations" `
            -d '{ "module_operation_type": "7", "receipt_cashier_name": "CASHIER", ... }'
